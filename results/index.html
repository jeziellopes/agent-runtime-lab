agent-runtime-lab · benchmark comparison

Framework Overhead

One agent runtime core, exposed through two HTTP adapters, NestJS and Hono, each run under both Node and Bun. Every scenario replays the same recorded token stream, so what differs between cells is the framework and the runtime, not the model. framework_overhead = request_latency − execution_duration.

Host AMD Ryzen 7 5800X 8-Core Processor · 8c/16t · 31 GB RAM · linux 6.8.0-136-generic Node 24.14.0 Bun 1.1.38 LLM mode replay

Limitations
  • Replay removes real provider latency.
  • The NestJS adapter bypasses @Sse(), so Nest's own SSE serializer is not measured.
  • Three cells are resident and idle during every measurement.
  • Scenario 05's latency comes from autocannon and is not comparable to scenarios 01 through 04.
  • Any cell needing workarounds has them disclosed as confounds.
  • The benchmark evaluates this architecture only.
